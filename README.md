# 🎙️ VoiceAttendAI

## 📌 Project Overview

VoiceAttendAI is a smart attendance management system developed using Python and Streamlit. It simplifies classroom attendance by allowing teachers to register students and record attendance through a voice-assisted interface. The project stores attendance records securely using SQLite and provides an easy-to-use dashboard.

---

## ✨ Features

- 👨‍🎓 Student Registration
- 🎤 Voice-Based Attendance
- 📅 Attendance History
- 📊 Dashboard
- 🗂️ SQLite Database
- 🎨 Streamlit User Interface

---

## 🚀 How to Run

1. Clone the repository

```
git clone https://github.com/preeticodes0506/VoiceAttendAI.git
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the project

```
streamlit run app.py
```
